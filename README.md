# Car-Evaluation-System
A machine learning-based system to evaluate and classify cars based on structural and comfort features like price, safety, and maintenance costs.An automated Car Evaluation System designed to analyze vehicle attributes and predict acceptability ratings using predictive modeling and data analysis.Predicts and evaluates vehicle acceptability.

# Car Evaluation System

## Project Overview
The Car Evaluation System is a Machine Learning
project that predicts car acceptability using
different car features.

## Objectives
- Analyze car evaluation data.
- Classify cars into different categories.
- Train a Decision Tree model.
- Visualize car evaluation results.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
Decision Tree Classifier

## Visualization Techniques
1. Car Category Distribution
2. Feature Importance
3. Decision Tree Visualization
4. Prediction Result

## How to Run

Install dependencies:

pip install -r requirements.txt

Execute:

python car_evaluation_visualization.py

## Output
Four visualization images are saved in the outputs folder.
